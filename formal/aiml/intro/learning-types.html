Introduction to AI/ML

Learning Types

How much help does the learner get from labelled answers?

Core types of learning

Supervised

Every example comes with its answer (label).

Unsupervised

No answers: find structure, such as groups.

Reinforcement

Act, then learn from rewards and penalties.

Self-supervised

The data labels itself: hide a part, predict it.

Advanced types of learning

Semi-supervised Weakly supervised Active Meta-learning Transfer Zero-, one-, few-shot Continual Online Multi-task Federated Representation

More on each in Learning Patterns.
