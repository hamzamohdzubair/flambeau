Color Spaces

The same colour can be written as different sets of numbers. Picking the right set makes a task easy.

What are colour spaces?

A colour space is a mathematical model for representing colours as numbers.

Why several? Different tasks need different representations.

RGB / BGR

Red, Green, Blue. Device-dependent.

Best for storage and transmission.

HSV

Hue, Saturation, Value. Perceptually intuitive.

Best for colour segmentation.

LAB

Lightness, A (green–red), B (blue–yellow).

Perceptually uniform.

RGB is standard in most libraries. BGR is OpenCV's default.

  • Why BGR? Historical reasons: early camera manufacturers and older image-processing libraries used it.
  • Important: always convert BGR to RGB before displaying with matplotlib.

The HSV colour space

  • Hue: the colour type. 0 to 179 in OpenCV, standing for 0 to 360° (halved to fit in a byte).
  • Saturation: colour intensity. 0 = gray, 255 = pure colour.
  • Value: brightness. 0 = black, 255 = brightest.
  • When to use: colour-based object detection, skin detection, colour segmentation.

BGR to RGB conversion


        import cv2

        # opencv uses BGR by default
        img_bgr = cv2.imread('image.jpg')
        # ans: blue, green, red order

        # convert to RGB
        img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)
        # ans: red, green, blue order

        # channels are swapped
        print(img_bgr[0, 0])  # [B, G, R]
        print(img_rgb[0, 0])  # [R, G, B]
        # ans: the same values, in a different order

Colour thresholding in HSV


        # detect red objects using HSV
        hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

        # define the red range (hue wraps around)
        lower_red = np.array([0, 100, 100])
        upper_red = np.array([10, 255, 255])
        # ans: hue 0-10 is red, with high saturation and value

        mask = cv2.inRange(hsv, lower_red, upper_red)
        # ans: binary mask: red regions are 255

        # apply the mask to extract red objects
        result = cv2.bitwise_and(img, img, mask=mask)
        # ans: keeps only the red regions

Try cv2.inRange

When H low > H high the range wraps through 179 → 0: two inRange masks joined with cv2.bitwise_or.

Split & merge channels


        # split BGR channels
        b, g, r = cv2.split(img)
        # ans: separate B, G, R channels (each is grayscale)

        # merge channels back
        merged = cv2.merge([b, g, r])
        # ans: reconstructs the original image

        # swap red and blue channels
        swapped = cv2.merge([r, g, b])
        # ans: BGR becomes RGB order: reds and blues trade places
