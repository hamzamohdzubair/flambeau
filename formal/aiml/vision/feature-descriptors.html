Feature Descriptors

Turn the neighbourhood of a keypoint into a vector of numbers, so the same point can be found in another image.

What are feature descriptors?

Descriptor: a numerical representation of a feature's local appearance.

  • Describes the feature's neighbourhood
  • Enables matching between images
  • Invariant to transformations (rotation, scale, illumination)

Descriptor properties

A good descriptor is…

Distinctive

Different features have different descriptors.

Invariant

Robust to rotation, scale and illumination.

Compact

A small memory footprint.

Fast

Quick to compute and to match.

Trade-off: invariance vs distinctiveness vs speed.

Types of descriptors

Classical

  • SIFT: Scale-Invariant Feature Transform
  • SURF: Speeded-Up Robust Features
  • ORB: Oriented FAST and Rotated BRIEF
  • BRIEF: Binary Robust Independent Elementary Features

Deep learning

  • CNN-based descriptors (covered in advanced topics)

The descriptor vector

A descriptor is a fixed-length vector of numbers.

Float vectors

SIFT: 128 floats · SURF: 64 or 128 floats

Binary vectors

ORB: 256 bits (32 bytes) · BRIEF: 128, 256 or 512 bits

Matching: compare the vectors with a distance metric.

ORB descriptor

ORB: Oriented FAST + Rotated BRIEF.

BRIEF compares the brightness of random pairs of points in the patch: 1 if the first is darker, 0 otherwise. 256 pairs give 256 bits.

  • Binary descriptor: fast to compute and match
  • Rotation invariant: the pairs are rotated to the keypoint's orientation
  • Scale invariant, using an image pyramid
  • Free to use (no patents)

Use case: real-time applications, mobile devices.

SIFT descriptor

SIFT: Scale-Invariant Feature Transform.

128 floats

A 128-dimensional float vector.

Gradient histograms

Histograms of gradient orientations around the keypoint.

Highly distinctive

Invariant to scale, rotation and illumination.

Disadvantage: slower; it was patented (the patent expired in 2020).

More in SIFT & SURF.

SURF descriptor

SURF: Speeded-Up Robust Features.

Faster than SIFT

Uses integral images for speed.

64 or 128 dims

Similar performance to SIFT.

Patented

Not available in OpenCV by default (it lives in the non-free contrib module).

Descriptor matching

Matching: find similar descriptors across images. Lower distance = better match.

L2 (Euclidean)

For float descriptors (SIFT, SURF)

\(d = \sqrt{\sum_i (d_1[i] - d_2[i])^2}\)

Hamming

For binary descriptors (ORB, BRIEF)

\(d\) = the number of differing bits

Brute-force matcher


        # create a BF matcher for ORB (Hamming distance)
        bf = cv2.BFMatcher(cv2.NORM_HAMMING, crossCheck=True)  # ans:
        # detect features in both images
        orb = cv2.ORB_create()
        kp1, des1 = orb.detectAndCompute(img1_gray, None)
        kp2, des2 = orb.detectAndCompute(img2_gray, None)
        # match descriptors
        matches = bf.match(des1, des2)  # ans:
        # sort by distance
        matches = sorted(matches, key=lambda x: x.distance)  # ans:
        # draw matches
        img_matches = cv2.drawMatches(img1, kp1, img2, kp2,
                                      matches[:50], None, flags=2)  # ans:

FLANN matcher

FLANN: Fast Library for Approximate Nearest Neighbors.

Advantage

Much faster for large datasets, because the search is approximate.

Trade-off

Speed vs accuracy.

FLANN in OpenCV


        # FLANN parameters for ORB
        FLANN_INDEX_LSH = 6
        index_params = dict(algorithm=FLANN_INDEX_LSH, table_number=6,
                            key_size=12, multi_probe_level=1)
        search_params = dict(checks=50)
        flann = cv2.FlannBasedMatcher(index_params, search_params)  # ans:
        # match descriptors
        orb = cv2.ORB_create()
        kp1, des1 = orb.detectAndCompute(img1_gray, None)
        kp2, des2 = orb.detectAndCompute(img2_gray, None)
        matches = flann.knnMatch(des1, des2, k=2)  # ans:
        # k=2 returns the 2 best matches per descriptor

Exercises 1 · concepts

What is a descriptor?

A numerical representation of a feature's local appearance.

Why do we need descriptors?

To match features across images.

What makes a good descriptor?

Distinctive, invariant, compact, fast.

What is the SIFT descriptor size?

128 dimensions (floats).

What is the ORB descriptor size?

256 bits (32 bytes).

Exercises 2 · concepts

Which distance for binary descriptors?

Hamming distance (count the differing bits).

Which distance for SIFT?

L2 (Euclidean) distance.

What are ORB's advantages over SIFT?

Faster, binary, free (no patent).

What is FLANN?

A fast approximate nearest-neighbour matcher.

What does crossCheck do in BFMatcher?

Keeps only mutual best matches (A→B and B→A).
