Feature extraction overview

Feature extraction: converting a raw image into meaningful measurements.

Low-level

Edges, corners, colours, textures.

Mid-level

SIFT, SURF, ORB descriptors.

High-level

Object parts, semantic concepts (CNNs).

Purpose: reduce dimensionality while keeping the important information.

Histogram of Oriented Gradients (HOG)

HOG describes local object appearance with gradient orientations.

  1. Compute gradients (magnitude + direction)
  2. Divide the image into cells (e.g. 8×8 pixels)
  3. Compute a histogram of gradients per cell (9 bins)
  4. Group cells into blocks (e.g. 2×2 cells)
  5. Normalise the histograms within each block
  6. Concatenate all histograms → the feature vector

Use case: pedestrian detection, object recognition.

HOG parameters

  • Cell size: 8×8 or 16×16 pixels
  • Block size: 2×2 or 3×3 cells
  • Orientations: 9 bins (0–180° for unsigned gradients)
  • Block stride: the overlap between blocks

Local Binary Patterns (LBP)

LBP is a texture descriptor.

  1. For each pixel, compare it with its 8 neighbours
  2. If neighbour ≥ centre: 1, else: 0
  3. Read the bits clockwise → an 8-bit binary number
  4. Convert to decimal (0–255)

Properties: rotation invariant (optionally) · grayscale invariant · fast to compute

Use case: texture classification, face recognition.

LBP implementation


          from skimage.feature import local_binary_pattern
          # compute LBP
          radius = 3
          n_points = 8 * radius
          lbp = local_binary_pattern(gray, n_points, radius, method='uniform')  # ans:
          # method options:
          # ans: 'default': the original LBP
          # ans: 'uniform': rotation invariant (most common)
          # ans: 'var': variance-based
          # create a histogram
          hist, _ = np.histogram(lbp.ravel(), bins=np.arange(0, n_points + 3),
                                 range=(0, n_points + 2))  # ans:
          hist = hist.astype('float')  # ans:
          hist /= (hist.sum() + 1e-7)  # normalise  # ans:

Colour histograms

Colour histogram: the distribution of colours in an image.

  1. Choose a colour space (RGB, HSV, LAB)
  2. Divide each channel into bins
  3. Count the pixels in each bin
  4. Normalise (make the sum = 1)

Use case: image retrieval, colour-based matching.

Colour histogram in OpenCV


        # compute a histogram for each channel
        hist_b = cv2.calcHist([img], [0], None, [256], [0, 256])  # ans:
        hist_g = cv2.calcHist([img], [1], None, [256], [0, 256])  # ans:
        hist_r = cv2.calcHist([img], [2], None, [256], [0, 256])  # ans:
        # parameters:
        # ans: [img]: the source image
        # ans: [0]: the channel index (0=B, 1=G, 2=R)
        # ans: None: no mask
        # ans: [256]: the number of bins
        # ans: [0, 256]: the range

Haar cascades

Haar cascades: pre-trained classifiers for object detection.

  • Haar-like features: rectangular patterns: sum of the white area minus sum of the black area
  • Cascade of weak classifiers: most windows are rejected by the first cheap stages
  • AdaBoost training picks the useful features

Pre-trained models: face, eyes, smile, full body… Advantage: fast, real-time detection.

Haar cascade in OpenCV


        # load the pre-trained face detector
        face_cascade = cv2.CascadeClassifier(
            cv2.data.haarcascades + 'haarcascade_frontalface_default.xml')  # ans:
        # detect faces
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        faces = face_cascade.detectMultiScale(gray, scaleFactor=1.1,
                                              minNeighbors=5, minSize=(30, 30))  # ans:
        # faces: an array of [x, y, w, h]
        for (x, y, w, h) in faces:  # ans:
            cv2.rectangle(img, (x, y), (x+w, y+h), (255, 0, 0), 2)  # ans:

Template matching

Template matching: find a template image inside a larger image.

  • TM_CCOEFF_NORMED: correlation coefficient (best)
  • TM_SQDIFF_NORMED: squared difference
  • TM_CCORR_NORMED: cross-correlation

Limitation: not scale- or rotation-invariant.

Template matching in OpenCV


        # load the template
        template = cv2.imread('template.jpg', 0)
        w, h = template.shape[::-1]
        # template matching
        result = cv2.matchTemplate(gray, template, cv2.TM_CCOEFF_NORMED)  # ans:
        # find the location of the best match
        min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(result)  # ans:
        # for CCOEFF_NORMED, higher is better
        top_left = max_loc  # ans:
        bottom_right = (top_left[0] + w, top_left[1] + h)  # ans:
        cv2.rectangle(img, top_left, bottom_right, (0, 255, 0), 2)  # ans:

What is the LBP output range?

0–255 (8-bit patterns from 8 neighbours).

Why normalise histograms?

To make them independent of image size: they sum to 1.

A series of weak classifiers that reject non-objects quickly.

TM_CCOEFF_NORMED (normalised correlation coefficient).
