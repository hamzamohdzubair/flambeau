Image Transforms

Move, turn, resize, mirror and cut images by changing where every pixel goes.

Types of transforms

Geometric transforms change pixel positions without changing the content.

Translation

Shift the image position.

Rotation

Rotate around a point.

Scaling

Resize the image.

Flipping

Mirror horizontally or vertically.

Affine

Any mix of the above. Parallel lines stay parallel.

Perspective

A 3-D-like change of viewpoint.

Translation

Translation shifts the image by \((t_x, t_y)\) pixels.

Transformation matrix

$$M = \begin{bmatrix} 1 & 0 & t_x \\ 0 & 1 & t_y \end{bmatrix}$$
  • Formula: \(x' = x + t_x\), \(y' = y + t_y\)
  • Positive \(t_x\) moves right, positive \(t_y\) moves down (image y grows downwards).
  • Use cases: positioning, data augmentation, image registration.

Translation in OpenCV


        import cv2
        import numpy as np
        # translation matrix (shift right 100, down 50)
        M = np.float32([[1, 0, 100],  # ans:
                        [0, 1, 50]])  # ans:
        # apply translation
        height, width = img.shape[:2]
        translated = cv2.warpAffine(img, M, (width, height))  # ans:
        # shift left (negative tx)
        M = np.float32([[1, 0, -50],
                        [0, 1,  0]])
        # ans: shifts 50 pixels left

Rotation

Rotation turns the image by an angle \(\theta\) around a centre \((c_x, c_y)\), optionally scaling by \(s\).

$$M = \begin{bmatrix} \alpha & \beta & (1-\alpha)\,c_x - \beta\,c_y \\ -\beta & \alpha & \beta\,c_x + (1-\alpha)\,c_y \end{bmatrix} \qquad \alpha = s\cos\theta,\ \ \beta = s\sin\theta$$
  • The third column moves the centre back where it was, so the image turns about \((c_x, c_y)\) instead of the top-left corner.
  • OpenCV builds it for you: cv2.getRotationMatrix2D(center, angle, scale). A positive angle turns the picture anticlockwise.

Rotation in OpenCV


        # get image center
        height, width = img.shape[:2]
        center = (width // 2, height // 2)
        # rotation matrix (45 degrees, no scaling)
        M = cv2.getRotationMatrix2D(center, 45, 1.0)  # ans:
        # ans: angle=45°, scale=1.0 (no resize)
        # apply rotation
        rotated = cv2.warpAffine(img, M, (width, height))  # ans:
        # rotate 90 degrees
        M = cv2.getRotationMatrix2D(center, 90, 1.0)
        rotated = cv2.warpAffine(img, M, (width, height))
        # ans: 90° anticlockwise: positive angles turn anticlockwise

Note the order: cv2.resize takes (width, height), but img.shape is (height, width).

Flipping

Flipping mirrors the image across an axis.

  • Horizontal: flipCode = 1 (left ↔ right)
  • Vertical: flipCode = 0 (top ↔ bottom)
  • Both: flipCode = -1 (same as a 180° rotation)
  • Use cases: data augmentation, mirror effects.

Transpose

Transpose swaps rows and columns: it reflects the image across its main diagonal, so width and height swap.

Original, 3×4

Transpose
cv2.transpose(img)

Rotate 90° clockwise
ROTATE_90_CLOCKWISE

Both are 4×3, but the pixels differ: a transpose is a 90° rotation plus a flip.

Transpose in OpenCV


        # transpose (swap width and height)
        transposed = cv2.transpose(img)  # ans:
        height, width = img.shape[:2]
        # ans: new shape = (width, height, channels)
        # transpose vs rotate 90°
        transposed = cv2.transpose(img)
        rotated = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)
        # ans: different results! transpose reflects across the diagonal
        # convenient rotation functions

        rot_180 = cv2.rotate(img, cv2.ROTATE_180)  # ans:
        rot_270 = cv2.rotate(img, cv2.ROTATE_90_COUNTERCLOCKWISE)  # ans:

Cropping

Cropping extracts a region of interest (ROI) with NumPy slicing: img[y1:y2, x1:x2]. No special OpenCV function needed.

Cropping in OpenCV


        # crop region [y1:y2, x1:x2]
        cropped = img[100:300, 50:250]  # ans:
        # ans: rows 100-300, columns 50-250
        # crop center region
        height, width = img.shape[:2]
        x = width // 4
        y = height // 4
        w = width // 2
        h = height // 2
        cropped = img[y:y+h, x:x+w]  # ans:
        # ans: center half of image

Rows come first: y before x. A slice is a view, so use .copy() if you will modify it.

Exercises 1 · concepts

What does translation do?

Shifts the image position by \((t_x, t_y)\).

What is the rotation centre?

The point the image rotates around.

Which interpolation is best for downscaling?

INTER_AREA or INTER_CUBIC (best quality).

What is flipCode=1?

A horizontal flip (left ↔ right).

What is the difference between transpose and rotate?

Transpose reflects across the diagonal; rotate turns without mirroring.

Exercises 2 · concepts

What happens to the size during rotation?

The output keeps the given size, so content may be clipped at the edges.

What are fx and fy in resize?

Scale factors for the x and y directions.

The fastest interpolation method?

INTER_NEAREST (nearest neighbour).

The best quality interpolation?

INTER_LANCZOS4 (slowest but best).

What is warpAffine used for?

Applying affine transformations: translation, rotation, scaling, shear.
