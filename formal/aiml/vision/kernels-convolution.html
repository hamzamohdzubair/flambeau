Kernels & Convolution

A tiny grid of weights, slid across an image, can blur it, sharpen it or find its edges.

What is a kernel?

A kernel (or filter) is a small matrix used to apply effects to an image.

Identity

Blur

Sharpen

  • Size: usually small (3×3, 5×5, 7×7) and odd-sized, so it has a centre pixel.
  • Purpose: it defines how to combine a pixel's neighbourhood into one new value.

What is convolution?

Convolution slides a kernel over an image and computes a weighted sum at every position.

  1. Place the kernel on an image region
  2. Multiply corresponding elements
  3. Sum all the products
  4. The sum is the new pixel value
  5. Slide the kernel to the next position and repeat

$$\text{Output}(x, y) = \sum_{i}\sum_{j} \text{Kernel}(i, j) \times \text{Image}(x + i,\ y + j)$$

\(i, j\) run over the kernel's offsets: −1, 0, 1 for a 3×3 kernel. Strictly this is correlation; true convolution flips the kernel first, which changes nothing for symmetric kernels. cv2.filter2D computes exactly this sum.

Edge handling

Problem: at a border pixel, the kernel extends beyond the image. Those five cells have no pixels, so we must invent values for them.

Zero paddingBORDER_CONSTANT
00abcde00
Border replicationBORDER_REPLICATE
aaabcdeee
ReflectionBORDER_REFLECT_101
cbabcdedc
Wrap aroundBORDER_WRAP
deabcdeab

OpenCV's default is cv2.BORDER_REFLECT_101: it mirrors without repeating the edge pixel.

          # apply convolution
          result = cv2.filter2D(img, -1, kernel)
          # ans: -1 means output has the same depth as the input
          # identity kernel returns the original image

          # 3x3 averaging kernel

          # sharpen kernel (enhances edges)
          kernel = np.array([[ 0, -1,  0],

          # ans: centre = 5, neighbours = -1, enhances differences

          # ans: edges become more pronounced

          # ans: it amplifies the centre and subtracts the neighbours

Kernel normalization

Why normalize? To keep the output in the valid range, 0 to 255. Divide by the sum of the kernel's weights.


          # unnormalized kernel
          kernel = np.array([[1, 2, 1],
                             [2, 4, 2],
                             [1, 2, 1]], dtype=np.float32)
          # sum of weights
          kernel_sum = kernel.sum()  # = 16
          # ans: sum = 1+2+1+2+4+2+1+2+1 = 16
          # normalize
          kernel_norm = kernel / kernel_sum
          # ans: ensures the output stays in range

Exercises 1 · concepts

What does convolution do?

Slides a kernel over the image and computes weighted sums.

Why are kernel sizes odd?

It needs a centre pixel, for symmetry.

What does this kernel do?


            kernel = np.array([[0, 0, 0],
                               [0, 1, 0],
                               [0, 0, 0]])

It is the identity kernel: it returns the original image unchanged.

What does a sum of weights equal to 1 ensure?

Brightness is preserved; nothing is amplified.

Exercises 2 · concepts

What kind of kernel detects vertical edges?

One with a [-1, 0, 1] pattern running horizontally.

What is the ddepth parameter of cv2.filter2D?


            result = cv2.filter2D(img, -1, kernel)

-1 means the output has the same depth as the source.

What is the difference between blur and sharpen kernels?

Blur averages (all weights positive); sharpen enhances (negative neighbours).

Why apply edge detection to grayscale?

It is simpler: one channel, and edges are changes in intensity.
