Matching approaches

Brute-force (BF)

Compare each descriptor in set 1 with all in set 2 and keep the closest. Simple, exact, slow for large sets.

FLANN

Fast Library for Approximate Nearest Neighbors. Tree-based search (KD-tree, LSH): much faster, slightly less accurate.

Press → to search with each. The pink star is the query descriptor.

Distance metrics

Float descriptors (SIFT, SURF)

L1 (Manhattan): \(\sum_i |d_1[i] - d_2[i]|\)

L2 (Euclidean): \(\sqrt{\sum_i (d_1[i] - d_2[i])^2}\)

Binary descriptors (ORB, BRIEF)

Hamming: the number of differing bits.

Hamming2: for ORB with WTA_K = 3 or 4, where bits come in pairs.

d₁ d₂ d₁ XOR d₂

count the 1s → distance = 0

Lower distance = better match. XOR and a bit count is all a binary match costs.

kNN matching

k-nearest neighbours returns the k best matches for each descriptor. Its purpose: enabling Lowe's ratio test.

Ratio test (Lowe's test)

Purpose: filter ambiguous matches. Accept a match only if the best is much closer than the second best.

Distinctive

best = 18
keep18 / 62 = 0.29
2nd best = 62

Ambiguous

best = 40
reject40 / 46 = 0.87
2nd best = 46

The amber mark is 0.75 × 2nd best: the best match must end before it. Typical thresholds: 0.7 to 0.8.

Ratio test in code


        bf = cv2.BFMatcher(cv2.NORM_HAMMING)
        matches = bf.knnMatch(des1, des2, k=2)
        # apply ratio test
        good_matches = []
        for m, n in matches:  # ans:
            if m.distance < 0.75 * n.distance:  # ans:
                good_matches.append(m)  # ans:
        # ans: keeps only distinctive matches

FLANN matcher

Advantages

  • Much faster for large descriptor sets
  • Approximate search: trades accuracy for speed
  • Different algorithms for different descriptor types

Algorithms

  • KD-tree: for SIFT, SURF (float)
  • LSH (locality-sensitive hashing): for ORB, BRIEF (binary)

FLANN for SIFT


        # FLANN parameters for SIFT (KD-tree)
        FLANN_INDEX_KDTREE = 1
        index_params = dict(algorithm=FLANN_INDEX_KDTREE, trees=5)
        search_params = dict(checks=50)
        flann = cv2.FlannBasedMatcher(index_params, search_params)  # ans:

        # ans: more trees = better accuracy, slower
        # checks: number of leaf nodes to search
        # ans: higher = better accuracy, slower

Homography filtering

Homography: a 3×3 perspective transformation matrix mapping points in one image to the other.

RANSAC (random sample consensus) iteratively fits the transformation to random samples and keeps the one most points agree with. Those points are the inliers; the rest are outliers.

Use case: filter geometric outliers after matching. Here RANSAC fits a line (2 points per sample); a homography needs 4.

Finding the homography


        # need at least 4 matches
        # extract matched point coordinates
        src_pts = np.float32([kp1[m.queryIdx].pt for m in good_matches]).reshape(-1, 1, 2)
        dst_pts = np.float32([kp2[m.trainIdx].pt for m in good_matches]).reshape(-1, 1, 2)
        # find homography with RANSAC
        M, mask = cv2.findHomography(src_pts, dst_pts, cv2.RANSAC, 5.0)  # ans:
        # M: 3x3 transformation matrix
        # ans: mask: inliers (1) vs outliers (0)
        # filter matches using mask
        inliers = [m for m, msk in zip(good_matches, mask.ravel()) if msk == 1]  # ans:

5.0 is the reprojection threshold in pixels: a match further than that from where M sends it is an outlier.

Exercises 1 · concepts

What is keypoint matching?

Finding corresponding features between images.

Which distance for binary descriptors?

Hamming distance.

What is crossCheck in BFMatcher?

It keeps only mutual best matches (bidirectional).

What is the ratio test?

Compare the best and second-best match; reject if they are similar.

A typical ratio test threshold?

0.75 (or the 0.7 to 0.8 range).

Exercises 2 · concepts

BF vs FLANN?

BF is exact but slow; FLANN is approximate but fast.

What is kNN matching?

Finding the k nearest neighbours for each descriptor.

Why k=2 for the ratio test?

We need the second-best match to compare with the best.

What is RANSAC?

Random sampling to find inliers and filter outliers.

What is a homography?

A 3×3 perspective transformation matrix.
