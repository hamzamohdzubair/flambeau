Noise & Blurring

Where the grain in an image comes from, and four filters that remove it without losing too much.

What is image noise?

Noise is random variation in pixel intensity: an unwanted signal on top of the real one.

Sources

  • Sensor imperfections
  • Low-light conditions
  • Electrical interference
  • Transmission errors
  • Compression artifacts

Impact

It degrades image quality and affects processing algorithms: edge detectors, thresholds and feature detectors all respond to noise as if it were detail.

Types of noise

Gaussian

  • Random values from a normal distribution
  • The most common type
  • Additive: noisy = clean + noise
  • Looks like a grainy texture

Salt-and-pepper

  • Random black and white pixels
  • Also called impulse noise
  • Pixels are either 0 or 255
  • Looks like random dots

Poisson

  • Varies with signal intensity
  • Common in low-light imaging
  • Variance proportional to intensity

Adding salt-and-pepper noise


        # add salt-and-pepper noise
        def add_salt_pepper(img, prob=0.01):
            noisy = img.copy()
            # salt (white pixels)
            num_salt = int(prob * img.size * 0.5)
            coords = [np.random.randint(0, i, num_salt) for i in img.shape[:2]]
            noisy[coords[0], coords[1]] = 255
            # pepper (black pixels)
            num_pepper = int(prob * img.size * 0.5)
            coords = [np.random.randint(0, i, num_pepper) for i in img.shape[:2]]
            noisy[coords[0], coords[1]] = 0
            return noisy
        # ans: prob controls the fraction of noisy pixels

Gaussian blur for noise reduction

Why Gaussian blur?

  • Effective for Gaussian noise
  • Weighted averaging: near pixels count more, so features survive better than with a box blur
  • Smooth, natural-looking results

Trade-off

It reduces noise but also blurs edges: the filter cannot tell an edge from noise.

Gaussian blur parameters


        # gaussian blur for noise reduction
        denoised = cv2.GaussianBlur(noisy, (5, 5), 0)  # ans:
        # ans: 5x5 kernel, sigma computed from the size
        # larger kernel for more smoothing
        denoised = cv2.GaussianBlur(noisy, (9, 9), 0)
        # ans: 9x9 kernel removes more noise, more blur
        # specific sigma value
        denoised = cv2.GaussianBlur(noisy, (0, 0), sigmaX=2.0)
        # ans: kernel size computed from sigma=2.0
        # different sigma for x and y
        denoised = cv2.GaussianBlur(noisy, (0, 0), sigmaX=2.0, sigmaY=1.0)
        # ans: anisotropic blur (different in x and y)

Median filter for salt-and-pepper

median → … mean → …
  • Not affected by outliers: it picks the middle value and ignores the extreme noise.
  • Preserves edges better than averaging.
  • Algorithm: sort the neighbourhood, pick the median.

Median blur in OpenCV


        # median blur (best for salt-and-pepper)
        denoised = cv2.medianBlur(noisy, 5)  # ans:
        # ans: 5x5 kernel, takes the median of 25 pixels
        # larger kernel for heavy noise
        denoised = cv2.medianBlur(noisy, 9)
        # ans: 9x9 kernel for strong salt-and-pepper noise
        # why does median work for salt-and-pepper?
        # ans: the median ignores extreme values (0 or 255)
        # ans: and keeps original pixel values better

Bilateral filter (edge-preserving)

Smooths noise while keeping edges sharp.

  • Two weights: spatial and intensity
  • Close pixels with similar intensity → high weight
  • Far pixels or different intensity → low weight
  • Best for: natural images, portrait smoothing
× =

Bright = high weight. The weights stop at the edge, so the two sides are never averaged together.

Bilateral filter in OpenCV


        # bilateral filter (edge-preserving denoising)
        denoised = cv2.bilateralFilter(noisy, d=9, sigmaColor=75, sigmaSpace=75)  # ans:
        # d: diameter of pixel neighborhood
        # ans: larger d = considers more neighbours, slower
        # sigmaColor: intensity difference threshold
        # ans: larger value = more colours averaged (more blur)
        # sigmaSpace: spatial distance threshold
        # ans: larger value = farther pixels considered
        # when to use bilateral?
        # ans: to preserve edges while removing noise
        # ans: better than Gaussian for natural images

Non-local means denoising

NLM compares patches, not just neighbourhoods.

  • Concept: similar patches anywhere in the image are averaged.
  • Advantage: better noise reduction, preserves texture.
  • Disadvantage: computationally expensive.

NLM denoising in OpenCV


        # non-local means denoising (grayscale)
        gray_noisy = cv2.cvtColor(noisy, cv2.COLOR_BGR2GRAY)
        denoised = cv2.fastNlMeansDenoising(gray_noisy, None, h=10,  # ans:
                                            templateWindowSize=7, searchWindowSize=21)  # ans:
        # for color images
        denoised = cv2.fastNlMeansDenoisingColored(noisy, None, h=10, hColor=10,  # ans:
                                                   templateWindowSize=7, searchWindowSize=21)  # ans:
        # h: filter strength
        # ans: higher h = more denoising, more blur
        # templateWindowSize: patch size
        # ans: usually 7x7
        # searchWindowSize: search area
        # ans: usually 21x21

Denoising, live

Comparing denoising methods

Gaussian blur

  • Fast, simple
  • Blurs edges
  • Good for light Gaussian noise

Median filter

  • Excellent for salt-and-pepper
  • Preserves edges
  • Slower than Gaussian

Bilateral filter

  • Edge-preserving
  • Good for natural images
  • Moderate speed

NLM denoising

  • Best quality
  • Preserves texture
  • Slowest
