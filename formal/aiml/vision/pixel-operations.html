NumPy vs OpenCV arithmetic

NumPy: modulo

255 + 10 = 9

Wraps around. Fast, but beware overflow.

OpenCV: saturated

cv2.add(255, 10) = 255

Clips to the max. Safe: it saturates.

Image addition


        import cv2
        import numpy as np
        # numpy addition (overflow)
        img = np.array([[250]], dtype=np.uint8)
        result = img + np.array([[10]], dtype=np.uint8)
        # ans: (250 + 10) % 256 = 4 (overflow!)
        # opencv addition (saturation)
        result = cv2.add(img, np.array([[10]], dtype=np.uint8))
        # ans: min(250 + 10, 255) = 255 (clips to max)

Brightening and darkening


        # brighten image (add constant)
        bright = cv2.add(img, np.array([50]))  # ans:
        # ans: adds 50 to all pixels (saturates at 255)
        # darken image (subtract constant)
        dark = cv2.subtract(img, np.array([50]))  # ans:
        # ans: subtracts 50 (saturates at 0)
        # alternative using numpy (watch overflow!)
        bright = np.clip(img.astype(int) + 50, 0, 255).astype(np.uint8)
        # ans: clip prevents overflow (do the sum in a wider type first)

A scalar passed as np.array([50]) is added to the first channel only on a colour image; use (50, 50, 50, 0) to shift all three.

Saturate or wrap?

The bright sky wraps past 255 into dark garbage; the saturated version just turns white.
