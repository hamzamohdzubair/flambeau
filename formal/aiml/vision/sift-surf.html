SIFT & SURF

Keypoints that survive zooming, turning and relighting, and the 128 numbers that describe each one.

SIFT overview

SIFT: Scale-Invariant Feature Transform (David Lowe, 1999).

Scale invariant

Detects features at multiple scales.

Rotation invariant

Assigns an orientation to each keypoint.

Illumination invariant

Robust to lighting changes.

Occlusion resistant

Copes with partial occlusion.

Patent expired in 2020: now free to use commercially (cv2.SIFT_create is in the main OpenCV package).

The SIFT algorithm

1Scale-space extrema

  • Build a Gaussian pyramid (multiple scales)
  • Compute the Difference of Gaussians (DoG)
  • Find local maxima/minima across scales

2Keypoint localization

  • Reject low-contrast points
  • Eliminate edge responses

3Orientation assignment

  • Compute a gradient histogram
  • Assign the dominant orientation(s)

4Descriptor generation

  • 16×16 neighbourhood → 4×4 grid
  • An 8-bin histogram per cell → 128 values

Scale-space detection

Why multiple scales?

  • Features appear at different sizes.
  • The same feature in different images may have different scales.

Gaussian pyramid

Original → Blur → Downsample → Blur → Downsample …

DoG (Difference of Gaussians) approximates the Laplacian:

$$\text{DoG} = G(k\sigma) - G(\sigma)$$

The SIFT descriptor

A 128-dimensional vector built from gradients around the keypoint:

  • Gradients of the 16×16 neighbourhood (arrows)
  • A 4×4 grid of cells, an 8-bin gradient histogram per cell
  • 4 × 4 × 8 = 128 values

Normalization makes it illumination invariant. Matching: L2 (Euclidean) distance.

SURF overview

SURF: Speeded-Up Robust Features (Herbert Bay, 2006).

3 to 5× faster

Uses integral images.

Comparable performance

Close to SIFT's matching quality.

64 or 128 dimensions

The extended descriptor has 128.

Caveat: still patented; it needs opencv-contrib (built with the non-free modules).

SURF's speed trick: integral images

image

integral image

  1. Integral images: each cell holds the sum of everything above and to its left, so any box sum costs 4 lookups.
  2. Hessian approximation: box filters instead of Gaussian derivatives, at any size for the same cost.
  3. Wavelet responses: simplified gradient computation.
  4. Steps similar to SIFT: scale-space detection (using the Hessian), orientation assignment, descriptor generation.

SIFT vs SURF

SIFT

  • More accurate, distinctive
  • Better for difficult matching
  • Slower (Gaussian filters)
  • 128 dimensions
  • Patent expired (free)

SURF

  • Faster (integral images)
  • Good for real-time
  • 64 or 128 dimensions
  • Still patented
  • A good SIFT alternative

Both: scale and rotation invariant, with robust descriptors.

Ratio test (Lowe's ratio)

Problem: ambiguous matches, when several descriptors look alike.

Solution: compare the best match with the second-best match.

0.75 is the standard threshold: lower it for stricter matching, raise it for looser.

See it filter real matches in Keypoint Matching.


          if distance(1st) < 0.75 * distance(2nd):
              accept match
          else:
              reject  # ambiguous

Ratio test implementation


        # BFMatcher with kNN (k=2)
        bf = cv2.BFMatcher(cv2.NORM_L2)
        matches = bf.knnMatch(des1, des2, k=2)  # ans:
        # ans: returns the 2 best matches for each descriptor
        # apply ratio test
        good_matches = []
        for m, n in matches:  # ans:
            if m.distance < 0.75 * n.distance:  # ans:
                good_matches.append(m)  # ans:
        # draw good matches
        img_matches = cv2.drawMatches(img1, kp1, img2, kp2, good_matches, None, flags=2)
