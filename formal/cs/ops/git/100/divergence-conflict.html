Divergence and Conflicts

What happens when you and a teammate both commit on top of the same history, and how a pull puts it back together.

What is divergence?

The same picture

Both histories start at A, then split: they have diverged.

If you pull with divergence

  • Git will not guess: it stops with fatal: Need to specify how to reconcile divergent branches.
  • It offers three strategies. Set one once with git config (add --global for every repository), or per pull with --no-rebase, --rebase or --ff-only.

Three ways to reconcile

When it becomes a conflict

If B and C changed the same lines, Git cannot combine them by itself. The merge (or rebase) stops and marks the file:


        <<<<<<< HEAD
        print("Hello, dog!")
        =======
        print("Hello, world!")
        >>>>>>> origin/main
  1. Edit the file to the version you want and delete the markers
  2. git add the file
  3. Finish with git commit (merge) or git rebase --continue (rebase)
