Basic Workflow

Where your changes live, and the commands that move them: add, commit, push, fetch, merge and pull.

Four places a change can be

The workflow at a glance

The six commands

git addWorking directory → staging area: choose what goes into the next commit
git commitStaging area → local repository: save a snapshot with a message
git pushLocal repository → remote: share your commits
git fetchRemote → local repository: download others' commits without touching your files
git mergeLocal repository → working directory: combine those commits with your work
git pullFetch and merge in one command
