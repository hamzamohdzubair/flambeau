High Level vs Low Level

The trade-off between how fast you can write a program and how fast it runs.

Trade-off chart

High-level language: code runs early, but more CPU time.

Low-level language: takes longer to get running, but ends up using less CPU time.

Development effort until the first runnable code that solves the problem: much less for high level.

Best possible performance after a significant amount of development effort: better for low level.
