If Statements

Run a block of code only when a condition is true, and choose between branches.

Basic if


        # simple if
        x = 10
        if x > 5:
            print("x is greater than 5")
        # ans: output: x is greater than 5
x =

The indented line runs only when the condition is True.

If-else


        # if with else
        age = 18
        if age >= 18:
            print("Adult")
        else:
            print("Minor")
        # ans: output: Adult

Exactly one of the two branches runs.

If-elif-else


          # multiple conditions
          score = 85
          if score >= 90:
              print("A")
          elif score >= 80:
              print("B")
          elif score >= 70:
              print("C")
          else:
              print("F")
          # ans: output: B
score =

Conditions are checked top to bottom; the first True one wins and the rest are skipped.

Nested if


        # if inside if
        x = 15
        if x > 10:
            if x < 20:
                print("Between 10 and 20")
        # ans: output: Between 10 and 20
x =

The inner if is only checked when the outer one is True.

Multiple elif


        # many elif branches
        num = 3
        if num == 1:
            print("One")
        elif num == 2:
            print("Two")
        elif num == 3:

Remember

Indentation is the block

Only the indented lines belong to the if; the next unindented line always runs.

First True wins

In an if / elif chain, Python stops at the first True condition and skips the rest.

Separate ifs are separate

Two if statements in a row are both checked.

Falsy values

0, None and an empty list [] all count as False.

pass

Does nothing: a placeholder for a block that must exist.
