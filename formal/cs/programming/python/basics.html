Variables and assignment

Variables and assignment


          # variable assignment
          x = 5
          name = "Alice"
          pi = 3.14
          # multiple assignment
          a, b, c = 1, 2, 3

Swapping values


          # swap values
          x, y = 10, 20
          x, y = y, x
          # ans: x is now 20, y is now 10

The right side, (20, 10), is built first; then both names are reassigned.

Variables · exercises 1

        # ans: 10
        # what happens after this swap?

        a, b = b, a
        # ans: a=15, b=5

Remember

Assignment

The right side is evaluated first; unpacking needs one name per value.

Types

/ always gives a float; True and False act as 1 and 0.

Logic

and / or short-circuit and return one of their operands.

Conversion

int() truncates; empty values and zero are falsy.

print

sep goes between values, end after them; it returns None.

Comments

# to the end of the line; triple-quoted strings for longer notes.
