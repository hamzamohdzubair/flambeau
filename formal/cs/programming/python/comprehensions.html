Comprehensions

Build lists, dicts, sets and generators in one readable line.

Anatomy of a list comprehension

[x**2 for x in range(10) if x % 2 == 0]

x**2

What to put in the new list, for each item.

for x in range(10)

Where the items come from.

if x % 2 == 0

Optional: which items to keep.

List comprehension: basics


        # basic list comprehension
        squares = [x**2 for x in range(10)]
        # ans: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

The same thing as a loop


          # equivalent to
          squares = []
          for x in range(10):
              squares.append(x**2)
          # ans: [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

The comprehension does exactly this: start empty, loop, append the expression each time.

Transforming each item


        # with transformation
        words = ["hello", "world", "python"]
        upper = [word.upper() for word in words]
        # ans: ['HELLO', 'WORLD', 'PYTHON']
        # with calculation
        prices = [19.99, 29.99, 39.99]
        with_tax = [price * 1.1 for price in prices]

Filtering with if


          # with condition (filter)
          evens = [x for x in range(10) if x % 2 == 0]
          # ans: [0, 2, 4, 6, 8]

Items that fail the condition are skipped; only the rest reach the new list.

More filters


        # multiple conditions
        numbers = [x for x in range(20) if x % 2 == 0 if x % 3 == 0]
        # ans: [0, 6, 12, 18]
        # condition with transformation
        numbers = [1, -2, 3, -4, 5]
        positive_squares = [x**2 for x in numbers if x > 0]
        # ans: [1, 9, 25]
        # filtering strings
        words = ["hello", "world", "python", "hi"]
        long_words = [word for word in words if len(word) > 3]
        # ans: ['hello', 'world', 'python']

if-else inside: choose, don't filter


        # if-else expression (not filter)
        numbers = [1, 2, 3, 4, 5]
        result = ["even" if x % 2 == 0 else "odd" for x in numbers]
        # ans: ['odd', 'even', 'odd', 'even', 'odd']

a if cond else b goes before the for and picks a value for every item; a filter if goes after and drops items.

Nested loops


        # nested loops
        matrix = [[i*j for j in range(3)] for i in range(3)]
        # ans: [[0, 0, 0], [0, 1, 2], [0, 2, 4]]
        # flatten nested list
        nested = [[1, 2], [3, 4], [5, 6]]
        flat = [item for sublist in nested for item in sublist]
        # ans: [1, 2, 3, 4, 5, 6]

Read the fors left to right, as if they were nested loops written top to bottom.

Dictionary comprehensions


        # basic dict comprehension
        squares = {x: x**2 for x in range(5)}
        # ans: {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}
        # from two lists
        keys = ["a", "b", "c"]
        values = [1, 2, 3]
        d = {k: v for k, v in zip(keys, values)}
        # ans: {'a': 1, 'b': 2, 'c': 3}

Dict comprehensions: filter and swap


        # with condition
        numbers = range(10)
        even_squares = {x: x**2 for x in numbers if x % 2 == 0}
        # ans: {0: 0, 2: 4, 4: 16, 6: 36, 8: 64}
        # swap keys and values
        original = {"a": 1, "b": 2, "c": 3}
        swapped = {v: k for k, v in original.items()}
        # ans: {1: 'a', 2: 'b', 3: 'c'}

Dict comprehensions: advanced


        # filter dictionary
        prices = {"apple": 0.5, "banana": 0.3, "cherry": 2.5}
        expensive = {k: v for k, v in prices.items() if v > 1.0}
        # ans: {'cherry': 2.5}
        # transform values
        prices = {"apple": 0.5, "banana": 0.3}
        with_tax = {k: v * 1.1 for k, v in prices.items()}
        # ans: {'apple': 0.55, 'banana': 0.33}

Transforming keys, nesting


        # transform keys
        data = {"name": "Alice", "age": 25}
        upper_keys = {k.upper(): v for k, v in data.items()}
        # ans: {'NAME': 'Alice', 'AGE': 25}
        # nested comprehension
        matrix = {i: {j: i*j for j in range(3)} for i in range(3)}

        # ans:  1: {0: 0, 1: 1, 2: 2},
        # ans:  2: {0: 0, 1: 2, 2: 4}}

Set comprehensions


        # basic set comprehension
        squares = {x**2 for x in range(10)}
        # ans: {0, 1, 4, 9, 16, 25, 36, 49, 64, 81}
        # with condition
        evens = {x for x in range(10) if x % 2 == 0}
        # ans: {0, 2, 4, 6, 8}

A set has no order: Python may print the items in a different order.

Sets remove duplicates


          # removes duplicates automatically
          numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
          unique = {x for x in numbers}
          # ans: {1, 2, 3, 4}

Sets from strings, set operations


        # from string
        text = "hello world"
        unique_chars = {char for char in text if char != ' '}
        # ans: {'h', 'e', 'l', 'o', 'w', 'r', 'd'}
        # set operations
        set1 = {x for x in range(5)}
        set2 = {x for x in range(3, 8)}
        intersection = {x for x in set1 if x in set2}
        # ans: {3, 4}

Generator expressions


        # generator expression (lazy evaluation)
        gen = (x**2 for x in range(10))
        # ans: <generator object>
        # iterate over generator
        for value in gen:
            print(value)
        # convert to list
        squares = list(x**2 for x in range(10))

Round brackets make a generator: it computes each value only when asked for it.

Memory efficient


        # memory efficient
        import sys
        list_comp = [x**2 for x in range(1000)]
        gen_exp = (x**2 for x in range(1000))
        sys.getsizeof(list_comp)  # ~9000 bytes
        sys.getsizeof(gen_exp)    # ~200 bytes
list~9000 B
generator~200 B

Generators in functions


        # use in functions
        sum(x**2 for x in range(10))
        # ans: 285
        max(x for x in range(10) if x % 2 == 0)
        # ans: 8

Inside a function call the extra brackets can be dropped.

Generators vs lists


        # list comprehension - all values in memory
        squares_list = [x**2 for x in range(1000000)]
        # generator - values created on demand
        squares_gen = (x**2 for x in range(1000000))

A generator runs only once


          # generators can only be iterated once
          gen = (x for x in range(3))
          list(gen)
          # ans: [0, 1, 2]
          list(gen)
          # ans: [] (exhausted)

Chaining generators


          # chaining generators
          numbers = (x for x in range(10))
          evens = (x for x in numbers if x % 2 == 0)
          squares = (x**2 for x in evens)
          result = list(squares)
          # ans: [0, 4, 16, 36, 64]

Nothing runs until list() asks; then each number flows through the whole chain before the next is read.

Practical examples


        # read file and process lines

Practical examples: matrices and counts


        # matrix operations
        matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

When to use comprehensions


        # good: simple transformation
        squares = [x**2 for x in numbers]
        # good: simple filter
        evens = [x for x in numbers if x % 2 == 0]
        # acceptable: moderate complexity
        result = [x**2 for x in numbers if x > 0 and x < 100]

Too complex? Use a loop


          # bad: too complex
          result = [
              process(x, y, z)
              for x in list1
              for y in list2
              if condition1(x)
              for z in list3
              if condition2(y, z)
          ]
        

          # use regular loop for readability
          result = []
          for x in list1:
              if condition1(x):
                  for y in list2:
                      for z in list3:
                          if condition2(y, z):
                              result.append(process(x, y, z))

Remember

[ ] list

[expr for x in items if cond]

{k: v} dict

{k: v for k, v in pairs}

{ } set

Like a list comprehension, but duplicates disappear.

( ) generator

Lazy: values made one at a time, usable once, tiny in memory.
