Iterate over a range

Break and continue

break: exit the loop


          # break - exit loop
          for i in range(10):
              if i == 5:
                  break
              print(i)
          # ans: 0, 1, 2, 3, 4

continue: skip this pass


          # continue - skip iteration
          for i in range(5):
              if i == 2:
                  continue
              print(i)
          # ans: 0, 1, 3, 4

Break in a nested loop


        # break in nested loop
        for i in range(3):
            for j in range(3):
                if j == 1:
                    break
                print(f"i={i}, j={j}")
        # ans: i=0,j=0 then i=1,j=0 then i=2,j=0

break leaves only the inner loop; the outer loop carries on. See the break & continue deck for this traced step by step.

Else with loops

for-else


          # for-else (runs if loop completes without break)
          for i in range(5):
              if i == 10:
                  break
          else:
              print("Loop completed")
          # ans: Loop completed

while-else


          # while-else
          count = 0
          while count < 3:
              print(count)
              count += 1
          else:
              print("While loop finished")
          # ans: 0, 1, 2, While loop finished

break prevents else


          # break prevents else
          for i in range(5):
              if i == 3:
                  break
          else:
              print("This won't print")
          # ans: nothing (break prevents else)

Think of the loop's else as "no break happened".

Match statement (Python 3.10+)

Basic match


          # basic match
          command = "start"
          match command:
              case "start":
                  print("Starting...")
              case "stop":
                  print("Stopping...")
              case "pause":
                  print("Pausing...")
              case _:
                  print("Unknown command")
          # ans: Starting...

Match with multiple values


          # match with multiple values
          status_code = 404
          match status_code:
              case 200 | 201:
                  print("Success")
              case 404:
                  print("Not Found")
              case 500 | 502 | 503:
                  print("Server Error")
              case _:
                  print("Other")
          # ans: Not Found

| means "or"; _ matches anything, so it goes last.

Pass statement

Pass: a placeholder


        # placeholder for empty blocks
        if True:
            pass
        # ans: nothing happens
        # empty function
        def my_function():
            pass
        # ans: function does nothing
        # empty class
        class MyClass:
            pass
        # ans: empty class definition

Python needs at least one statement in every block; pass is the statement that does nothing.

Remember

if / elif / else

The first True branch runs; falsy values (0, None, empty) count as False.

Ternary

a if cond else b picks a value in one expression.

for and while

for walks over items; while repeats while a condition holds.

break / continue

Leave the innermost loop, or skip to its next pass.

Loop else

Runs when the loop ends without a break.

match / pass

First matching case wins, _ last; pass fills an empty block.
