Data Types

Every value in Python has a type: whole numbers, decimals, text, truth values and "nothing".

Integer type


        # integer
        age = 25
        type(age)
        # ans: <class 'int'>
        count = -10
        # ans: negative integer
        big_num = 1000000
        # ans: large integer

Whole numbers, positive or negative, with no size limit.

Float type


        # float
        price = 19.99
        type(price)
        # ans: <class 'float'>
        pi = 3.14159
        # ans: float value
        negative = -5.5
        # ans: negative float

Numbers with a decimal point.

String type


        # string
        message = "Hello"
        type(message)
        # ans: <class 'str'>
        name = 'Alice'
        # ans: single quotes
        text = """multi
        line"""
        # ans: multiline string

Text, in single, double or triple quotes.

Boolean type


        # boolean
        is_valid = True
        type(is_valid)
        # ans: <class 'bool'>
        is_empty = False
        # ans: False value

Exactly two values, True and False, with capital letters.

NoneType


        # None type
        x = None
        type(x)
        # ans: <class 'NoneType'>
        # ans: represents absence of value
        result = None
        # ans: no value yet

Checking types


        # type() function
        x = 5
        type(x)
        # ans: <class 'int'>
        y = "hello"
        type(y)
        # ans: <class 'str'>
        z = 3.14
        type(z)
        # ans: <class 'float'>

Every value lands in one type

int

float

str

bool

NoneType

Python evaluates the expression first; the type belongs to the resulting value.

Exercises

Name the type before you reveal it.

Exercise 1


        # what type is this?
        x = 5.0
        # ans: <class 'float'>
        # what type is this?
        y = "123"
        # ans: <class 'str'>
        # what type results?
        result = 10 / 2
        # ans: <class 'float'>
        # what type is this?
        z = True + False
        # ans: <class 'int'> (True=1, False=0)

Exercise 2


        # what type?
        a = 5
        b = 2
        c = a / b
        # ans: <class 'float'>
        # what type?
        x = 10
        y = 3
        z = x // y
        # ans: <class 'int'>

/ always gives a float; // on two ints gives an int.

Exercise 3


        # tricky: what type?
        value = "5" + "3"
        # ans: <class 'str'> (result is "53")
        # what is the type?
        x = None
        # ans: <class 'NoneType'>
        # what type is this expression?
        result = 5 > 3
        # ans: <class 'bool'>

Exercise 4


        # what happens?
        x = int(True)
        # ans: 1, type is <class 'int'>
        # mixing types?
        x = 5 + 2.5
        # ans: 7.5, type is <class 'float'>
        # edge case?
        x = bool([])
        # ans: False, type is <class 'bool'>

Exercise 5


        # what type?
        x = 0
        # ans: <class 'int'>
        # empty string type?
        s = ""
        # ans: <class 'str'>
        # what type?
        x = float(5)
        # ans: 5.0, <class 'float'>

Remember

int and float

Whole numbers and decimals. Mixing them, or dividing with /, gives a float.

str

Text in quotes. "5" + "3" joins text: "53".

bool

True and False; they behave like 1 and 0 in arithmetic.

None

The single value of NoneType: "no value yet".

type(x)

Asks any value for its type.
