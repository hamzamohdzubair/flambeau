File Paths

Check whether files exist, build paths that work on every system, and take paths apart with os.path and pathlib.

os module: basic checks


        import os
        # check if exists
        os.path.exists("file.txt")
        # ans: True or False
        # check if file
        os.path.isfile("file.txt")
        # ans: True or False
        # check if directory
        os.path.isdir("folder")
        # ans: True or False

os module: path info


        import os
        # file size
        os.path.getsize("file.txt")
        # ans: size in bytes
        # absolute path
        os.path.abspath("file.txt")
        # ans: /full/path/to/file.txt

abspath glues the current working directory onto a relative path.

os module: joining paths


        import os
        # join paths
        os.path.join("folder", "file.txt")
        # ans: folder/file.txt
        # ans: works across platforms

os module: splitting paths


        import os
        # directory name
        os.path.dirname("/path/to/file.txt")
        # ans: "/path/to"
        # base name
        os.path.basename("/path/to/file.txt")
        # ans: "file.txt"
        # split extension
        os.path.splitext("file.txt")
        # ans: ("file", ".txt")

The pathlib module


        from pathlib import Path
        # create path object
        path = Path("file.txt")
        # check exists
        path.exists()
        # ans: True or False
        # read file
        content = path.read_text()

A Path is an object with methods, instead of a plain string passed to os.path functions.

pathlib: path parts


        from pathlib import Path
        path = Path("/folder/file.txt")
        # name
        path.name
        # ans: "file.txt"
        # stem
        path.stem
        # ans: "file"
        # suffix
        path.suffix
        # ans: ".txt"
        # parent
        path.parent
        # ans: Path("/folder")

The anatomy of a path

pathlib names on top, the matching os.path function underneath. os.path.splitext splits off the same suffix, which is only the last extension.

Remember

Check

exists is True for files and folders; isfile and isdir tell them apart.

Build

os.path.join or Path(...) / "name" pick the right separator for the system.

Take apart

parent/dirname, name/basename, stem and suffix/splitext.

Where am I?

Relative paths start from os.getcwd(); abspath makes them absolute.
