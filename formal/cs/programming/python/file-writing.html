File Writing

Create files, replace their contents or add to the end, and know exactly what ends up on disk.

Write mode


          # write to file (overwrites)
          with open("output.txt", "w") as file:
              file.write("Hello, World!")

Opening with "w" empties the file straight away (or creates it if it is missing).

Write multiple lines


          # write several lines
          with open("output.txt", "w") as file:
              file.write("Line 1\n")
              file.write("Line 2\n")
              file.write("Line 3\n")

Each line needs its own \n; write never adds one.

writelines


          # write list of lines
          lines = ["Line 1\n", "Line 2\n", "Line 3\n"]
          with open("output.txt", "w") as file:
              file.writelines(lines)

Append mode


          # append to existing file
          with open("output.txt", "a") as file:
              file.write("Appended line\n")

With "a" the old contents stay and the cursor starts at the end.

write returns a count


          # write returns character count
          with open("output.txt", "w") as file:
              count = file.write("Hello")
          # ans: count is 5

              f.write("Line 1")

          with open("new.txt", "a") as f:

Convert first: f.write(str(42)).

Exercise 10


          # write binary?
          with open("file.bin", "wb") as f:
              f.write(b"data")
          # ans: writes bytes

In binary mode, write takes bytes (note the b prefix), not str.

Remember

"w"

Empties the file (or creates it), then writes from the start.

"a"

Keeps what is there and writes at the end; creates the file if needed.

No automatic newlines

write and writelines write exactly the strings you give, so add \n yourself.

Strings only

write returns the number of characters; numbers must go through str(); binary mode takes bytes.
