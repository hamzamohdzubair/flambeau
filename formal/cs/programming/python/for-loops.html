For Loops

Run the same block once for every item in a sequence: numbers, list items or characters.

Basic for loop


          # iterate over range
          for i in range(5):
              print(i)
          # ans: prints 0, 1, 2, 3, 4 (one per line)
range(5)

Each pass, i takes the next value from range(5); the loop stops when the values run out.

Range with start and stop


          # range(start, stop)
          for i in range(2, 7):
              print(i)
          # ans: 2, 3, 4, 5, 6
range(2, 7): the stop value 7 is not included

Range with a step


          # range(start, stop, step)
          for i in range(0, 10, 2):
              print(i)
          # ans: 0, 2, 4, 6, 8
range(0, 10, 2): count up in twos

How range() counts

Start at start, add step each time, and stop before reaching stop.

Iterate over a list


          # iterate list items
          fruits = ["apple", "banana", "cherry"]
          for fruit in fruits:
              print(fruit)
          # ans: apple, banana, cherry (one per line)
fruits

No index needed: the loop variable is each item itself.

Iterate with an index


          # enumerate for index and value
          fruits = ["apple", "banana"]
          for i, fruit in enumerate(fruits):
              print(i, fruit)
          # ans: 0 apple
          # ans: 1 banana
enumerate(fruits) hands out (index, item) pairs

Iterate over a string


          # iterate over characters
          for char in "abc":
              print(char)
          # ans: a, b, c (one per line)
a string is a sequence of characters

Remember

range(stop)

Counts from 0 up to, but not including, stop.

range(start, stop, step)

A negative step counts down; an empty range runs the body zero times.

Any sequence

Lists, strings and enumerate(...) pairs all work in a for.

The loop variable

Keeps its last value after the loop; reassigning it inside does not change what comes next.
