Python · functions

Functions

Name a piece of code, give it inputs, get a result back: parameters, return values, lambdas, scope, recursion and type hints.

Basic functions


          # simple function
          def greet():
              print("Hello!")
          greet()

          # function with parameters
          def greet_person(name):
              print(f"Hello, {name}!")
          greet_person("Alice")

          # function with return value
          def add(a, b):
              return a + b
          result = add(5, 3)  # 8

Press → to run it. def only stores the function; its body runs when it is called, in a fresh frame.

Default parameters


        # default parameter values
        def greet(name="Guest"):
            print(f"Hello, {name}!")

        greet()           # Hello, Guest!
        greet("Alice")    # Hello, Alice!

Multiple defaults


        # multiple defaults
        def create_profile(name, age=0, country="Unknown"):
            return f"{name}, {age}, {country}"

        create_profile("Alice")               # Alice, 0, Unknown
        create_profile("Bob", 25)             # Bob, 25, Unknown
        create_profile("Charlie", 30, "USA")  # Charlie, 30, USA

Arguments fill parameters left to right; any parameter left over takes its default.

Keyword arguments


        # keyword arguments
        def describe_pet(animal, name):
            print(f"I have a {animal} named {name}")

        describe_pet(animal="dog", name="Rex")
        describe_pet(name="Whiskers", animal="cat")

        # mixing positional and keyword
        describe_pet("hamster", name="Fluffy")

With keywords, order no longer matters. Positional arguments must come first.

Variable arguments


        # *args - arbitrary positional arguments
        def sum_all(*numbers):
            return sum(numbers)

        sum_all(1, 2, 3)        # 6
        sum_all(1, 2, 3, 4, 5)  # 15

        # **kwargs - arbitrary keyword arguments
        def print_info(**info):
            for key, value in info.items():
                print(f"{key}: {value}")

        print_info(name="Alice", age=25, city="NYC")
        # ans: name: Alice / age: 25 / city: NYC

Combining them all


          # combining all
          def func(a, b, *args, key1="default", **kwargs):
              print(a, b)
              print(args)
              print(key1)
              print(kwargs)

          func(1, 2, 3, 4, key1="value", x=10, y=20)

Watch the call's frame: extra positional arguments are packed into the tuple args, extra keywords into the dict kwargs.

Return values


        # single return
        def square(x):
            return x ** 2

        # multiple return values
        def divide(a, b):
            quotient = a // b
            remainder = a % b
            return quotient, remainder

        q, r = divide(17, 5)  # q=3, r=2

Early return, and no return


        # early return
        def is_even(n):
            if n % 2 == 0:
                return True
            return False

        # no return (returns None)
        def print_message(msg):
            print(msg)

        result = print_message("Hi")  # result is None

Lambda functions


        # basic lambda
        square = lambda x: x ** 2
        square(5)  # 25

        # lambda with multiple parameters
        add = lambda x, y: x + y
        add(3, 4)  # 7

A lambda is a one-expression function without a name: lambda params: expression.

Lambdas as arguments


        # lambda in sorted
        pairs = [(1, 'one'), (3, 'three'), (2, 'two')]
        sorted(pairs, key=lambda pair: pair[1])
        # ans: [(1, 'one'), (3, 'three'), (2, 'two')]

        # lambda in map
        numbers = [1, 2, 3, 4, 5]
        squared = list(map(lambda x: x ** 2, numbers))
        # ans: [1, 4, 9, 16, 25]

        # lambda in filter
        evens = list(filter(lambda x: x % 2 == 0, numbers))
        # ans: [2, 4]

Scope: global and local


          # global scope
          x = 10
          def func():
              # local scope
              y = 20
              print(x)  # can access global
              print(y)  # local variable

          func()
          # print(y)  # Error: y not defined

y lives in func's frame, so it disappears when the call ends.

The global keyword


          # global keyword
          count = 0
          def increment():
              global count
              count += 1

          increment()
          print(count)  # 1

Without global, count += 1 would try to change a local count that doesn't exist yet.

The nonlocal keyword


          # nonlocal keyword
          def outer():
              x = 10
              def inner():
                  nonlocal x
                  x = 20
              inner()
              print(x)  # 20

          outer()

nonlocal points x at the enclosing function's frame. More in Scope.

Docstrings


        # function documentation
        def calculate_area(radius):
            """
            Calculate the area of a circle.

            Parameters:
                radius (float): The radius of the circle

            Returns:
                float: The area of the circle
            """
            return 3.14 * radius ** 2

        # accessing docstring
        print(calculate_area.__doc__)
        help(calculate_area)

Recursion


          # factorial
          def factorial(n):
              if n <= 1:
                  return 1
              return n * factorial(n - 1)

          factorial(5)  # 120

Each call waits on the stack for the one above it. The base case n <= 1 stops the growth, then the answers flow back down.

More recursion


          # fibonacci
          def fibonacci(n):
              if n <= 1:
                  return n
              return fibonacci(n - 1) + fibonacci(n - 2)

          fibonacci(6)  # 8
        

          # sum of list
          def sum_list(lst):
              if not lst:
                  return 0
              return lst[0] + sum_list(lst[1:])

          sum_list([1, 2, 3, 4])  # 10

Every recursive function needs a base case that returns without calling itself.

Type hints


        # basic type hints
        def greet(name: str) -> str:
            return f"Hello, {name}!"

        def add(a: int, b: int) -> int:
            return a + b

        # multiple types
        from typing import Union
        def process(value: Union[int, str]) -> str:
            return str(value)

Hints document what a function expects and returns. Python does not enforce them; tools like mypy and your editor check them.

Container and optional types


        # list and dict types
        from typing import List, Dict
        def sum_list(numbers: List[int]) -> int:
            return sum(numbers)

        def get_config() -> Dict[str, str]:
            return {"key": "value"}

        # optional
        from typing import Optional
        def find_user(user_id: int) -> Optional[str]:
            return "Alice" if user_id == 1 else None

Since Python 3.9 and 3.10 you can also write list[int], dict[str, str] and str | None without importing from typing.

Remember

A call gets a frame

Parameters and local variables live in it, and vanish when the call returns.

Flexible inputs

Defaults, keywords, *args (a tuple) and **kwargs (a dict).

return

Hands one value back (several become a tuple); none means None.

Scope

Read outer names freely; change them with global or nonlocal.

Recursion

A function calling itself, with a base case to stop.
