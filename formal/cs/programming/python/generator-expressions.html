Generator Expressions

A comprehension in round brackets: it describes the values, and computes each one only when it is asked for.

Basic generator expression


          # generator expression (lazy)
          gen = (x**2 for x in range(5))
          # ans: <generator object>
          list(gen)
          # ans: [0, 1, 4, 9, 16]

Making gen computes nothing. list() pulls the values through one by one, squaring each as it passes.

Generator vs list


        # list - all in memory
        lst = [x**2 for x in range(1000)]
        # generator - on demand
        gen = (x**2 for x in range(1000))

List: all 1000 squares are stored

computed up front, held in memory

Generator: one at a time

0

x = 0: only the current value exists

Iterating a generator


          # iterate once
          gen = (x for x in range(3))
          for val in gen:
              print(val)
          # ans: 0, 1, 2
          # ans: exhausted after iteration
          for val in gen:
              print(val)
          # ans: (nothing)

Generators inside function calls


        # use in sum
        sum(x**2 for x in range(10))
        # ans: 285
        # use in max
        max(x for x in range(10) if x % 2 == 0)
        # ans: 8

When the generator is the only argument, its own brackets can be dropped. No list is ever built.

Generator with a condition


          # filter with generator
          gen = (x for x in range(10) if x % 2 == 0)
          list(gen)
          # ans: [0, 2, 4, 6, 8]

Odd values are checked and skipped (red); only even ones come out.

Remember

Round brackets

(expr for x in it if cond) makes a generator, not a tuple.

Lazy

Values are computed when asked for, so memory stays tiny.

One pass

After it is exhausted, it gives nothing more.

Feed functions

sum, max, list and friends consume generators directly.
