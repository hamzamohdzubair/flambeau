Python · basics

Input & Output

Everything print() does: several values, separators, line endings and escape characters.

What print() does

1. Turn values into text

Each argument is converted with str().

2. Join with sep

The texts are joined by the separator, a space unless you say otherwise.

3. Add end

Then end is added, a newline unless you say otherwise, and the result is written to the screen.

Basic print


          # simple print
          print("Hello, World!")
          # ans: Hello, World!
          print("Python")
          # ans: Python

Print multiple values


          # multiple arguments
          print("Age:", 25)
          # ans: Age: 25
          print("Name:", "Alice", "Score:", 95)
          # ans: Name: Alice Score: 95

Print separator


          # custom separator
          print("a", "b", "c", sep="-")
          # ans: a-b-c
          print(1, 2, 3, sep=" | ")
          # ans: 1 | 2 | 3

Print end character


          # custom end character
          print("Hello", end="")
          print("World")
          # ans: HelloWorld
          print("Line1", end=" ")
          print("Line2")
          # ans: Line1 Line2

With end="" the cursor stays on the same line, so the next print carries on there.

Print expressions


          # print with expression
          print(5 + 3)
          # ans: 8
          x = 10
          print("x =", x)
          # ans: x = 10

Expressions are worked out first; print only sees the results.

Remember

sep

Goes between values; default " ".

end

Goes after the last value; default "\n".

Escapes

\n new line, \t tab, \" a quote; a raw string r"..." keeps backslashes.

Returns None

print shows text; it doesn't give a value back.
