Python · iterators & generators

Iterators

The protocol behind every for loop: iter() makes a cursor, next() moves it, StopIteration says it's done.

The iterator protocol


          # get iterator
          numbers = [1, 2, 3]
          iterator = iter(numbers)
          # call next
          next(iterator)
          # ans: 1
          next(iterator)
          # ans: 2
          next(iterator)
          # ans: 3
          next(iterator)
          # ans: StopIteration

The iterator remembers its position; the list itself is unchanged.

A for loop uses iterators


          # for loop = iterator protocol
          for num in [1, 2, 3]:
              print(num)
        

          # equivalent to:
          iterator = iter([1, 2, 3])
          while True:
              try:
                  num = next(iterator)
                  print(num)
              except StopIteration:
                  break

A custom iterator


          # iterator class
          class Counter:
              def __init__(self, start, end):
                  self.current = start
                  self.end = end
              def __iter__(self):
                  return self
              def __next__(self):
                  if self.current >= self.end:
                      raise StopIteration
                  self.current += 1
                  return self.current - 1

          for num in Counter(0, 3):
              print(num)
          # ans: 0, 1, 2

Any object with __iter__ and __next__ works in a for loop.

Iterable vs iterator


          # iterable: has __iter__()
          # iterator: has __iter__() and __next__()

          # list is iterable but not iterator
          numbers = [1, 2, 3]
          iter(numbers)
          # ans: works
          next(numbers)
          # ans: TypeError
          # iterator is both
          iterator = iter(numbers)
          iter(iterator)
          # ans: returns itself
          next(iterator)
          # ans: 1

Remember

Iterable

Can make an iterator: iter(x) works. Lists, strings, ranges, dicts.

Iterator

Hands out values with next() and remembers where it is.

StopIteration

Signals the end; a for loop catches it and stops.

One pass

An exhausted iterator stays empty; call iter() again for a fresh one.
