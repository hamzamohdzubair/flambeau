Lambda Functions

Small, nameless, one-expression functions, written right where you need them.

Basic lambda


        # lambda syntax
        square = lambda x: x ** 2
        result = square(5)
        # ans: 25

A lambda is a short def

lambda square = lambda x: x ** 2
def def square(x): return x ** 2
The keyword lambda replaces def and the name. Parameters come before the colon, without brackets. The body is one expression, and its value is returned automatically: no return.

Lambda with multiple parameters


        # multiple parameters
        add = lambda x, y: x + y
        result = add(3, 4)
        # ans: 7

Lambda in sorted


        # lambda as key function
        pairs = [(1, 'one'), (3, 'three'), (2, 'two')]
        sorted_pairs = sorted(pairs, key=lambda pair: pair[1])
        # ans: [(1, 'one'), (3, 'three'), (2, 'two')]

Lambda in map


          # lambda with map
          numbers = [1, 2, 3, 4, 5]
          squared = list(map(lambda x: x ** 2, numbers))
          # ans: [1, 4, 9, 16, 25]

map calls the lambda on every item.

Lambda in filter


          # lambda with filter
          numbers = [1, 2, 3, 4, 5]
          evens = list(filter(lambda x: x % 2 == 0, numbers))
          # ans: [2, 4]

filter keeps the items for which the lambda returns True.

Exercise 4


        # lambda vs def?
        f = lambda x: x ** 2
        def g(x):
            return x ** 2
        f(3) == g(3)
        # ans: True

Exercise 5


        # lambda with conditional?
        abs_val = lambda x: x if x >= 0 else -x
        abs_val(-5)
        # ans: 5

Exercise 6


        # can lambda have multiple lines?
        f = lambda x: x + 1
                      x + 2
        # ans: SyntaxError (a lambda is a single expression)

Exercise 7


        # lambda in list?
        funcs = [lambda x: x+1, lambda x: x*2]
        funcs[0](5)
        # ans: 6

Exercise 8


        # lambda with default argument?
        f = lambda x=5: x * 2
        f()
        # ans: 10

Exercise 9


        # nested lambda?
        f = lambda x: (lambda y: x + y)
        f(5)(3)
        # ans: 8

f(5) returns lambda y: 5 + y, which is then called with 3.

Exercise 10


        # lambda without parameter?
        f = lambda: 42
        f()
        # ans: 42

Remember

Shape

lambda params: expression, with the value returned automatically.

One expression

No statements, no multiple lines; use def for anything bigger.

Best as arguments

Short keys and tests for sorted, map and filter.
