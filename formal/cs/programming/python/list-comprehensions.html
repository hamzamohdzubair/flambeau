List Comprehensions

Build a new list from an iterable in one readable line: transform each item, and optionally filter.

Reading a comprehension

[x**2 for x in range(10) if x % 2 == 0]

for clause

Runs first: where the items come from, one at a time.

condition (optional)

Checked next: items that fail it are skipped.

expression

Written first, computed last: what goes into the new list for each kept item.

Basic list comprehension


          # basic comprehension
          squares = [x**2 for x in range(5)]
          # ans: [0, 1, 4, 9, 16]

With a transformation


          # transform items
          words = ["hello", "world"]
          upper = [word.upper() for word in words]
          # ans: ['HELLO', 'WORLD']

With a condition (filter)


          # filter with condition
          evens = [x for x in range(10) if x % 2 == 0]
          # ans: [0, 2, 4, 6, 8]

Multiple conditions


          # multiple filters
          numbers = [x for x in range(20)
                     if x % 2 == 0
                     if x % 3 == 0]
          # ans: [0, 6, 12, 18]

Two if clauses must both pass, like and.

If-else expression


          # if-else (not filter)
          result = ["even" if x % 2 == 0 else "odd"
                    for x in range(5)]
          # ans: ['even', 'odd', 'even', 'odd', 'even']

An if-else before for chooses a value for every item; an if after for drops items.

Nested loops


          # nested loops
          pairs = [(x, y) for x in range(3)
                          for y in range(2)]
          # ans: [(0,0), (0,1), (1,0), (1,1), (2,0), (2,1)]

The first for is the outer loop: y runs through all its values for each x.

Flatten a nested list


          # flatten
          nested = [[1, 2], [3, 4], [5, 6]]
          flat = [item for sublist in nested
                       for item in sublist]
          # ans: [1, 2, 3, 4, 5, 6]

Remember

Shape

[expression for item in iterable if condition]

Filter vs choose

if after for drops items; a if c else b before for picks a value.

Loops nest left to right

The first for is the outer loop, as in the equivalent nested loops.

Keep it readable

If it no longer fits on a line or two, write the loop instead.
