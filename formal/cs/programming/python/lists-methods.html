List Methods

Add, remove, reorder and search: the methods that change a list in place.

append


          # add to end
          fruits = ["apple", "banana"]
          fruits.append("cherry")
          # ans: ["apple", "banana", "cherry"]

insert


          # insert at index
          fruits = ["apple", "cherry"]
          fruits.insert(1, "banana")
          # ans: ["apple", "banana", "cherry"]

Everything from index 1 onwards shifts one place right to make room.

extend


          # add multiple items
          fruits = ["apple"]
          fruits.extend(["banana", "cherry"])
          # ans: ["apple", "banana", "cherry"]

remove


          # remove by value
          fruits = ["apple", "banana", "cherry"]
          fruits.remove("banana")
          # ans: ["apple", "cherry"]

pop


          # remove and return
          fruits = ["apple", "banana", "cherry"]
          last = fruits.pop()
          # ans: last is "cherry"
          # ans: fruits is ["apple", "banana"]
          first = fruits.pop(0)
          # ans: first is "apple"

Without an index, pop() takes the last item; pop(0) takes the first.

sort


          # sort in place
          numbers = [3, 1, 4, 1, 5]
          numbers.sort()
          # ans: [1, 1, 3, 4, 5]
          numbers.sort(reverse=True)
          # ans: [5, 4, 3, 1, 1]

reverse


          # reverse in place
          lst = [1, 2, 3]
          lst.reverse()
          # ans: [3, 2, 1]

count


          # count occurrences
          numbers = [1, 2, 3, 2, 4, 2]
          numbers.count(2)
          # ans: 3

index


          # find index
          fruits = ["apple", "banana", "cherry"]
          fruits.index("banana")
          # ans: 1

index scans from the left and stops at the first match.

clear


          # remove all
          fruits = ["apple", "banana"]
          fruits.clear()
          # ans: []
