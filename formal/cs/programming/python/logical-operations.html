Logical Operations

Combine conditions with and, or and not, and see why Python sometimes stops early.

The and operator


          # and - both must be True
          True and True
          # ans: True
          True and False
          # ans: False
          False and True
          # ans: False
          False and False
          # ans: False

The or operator


          # or - at least one True
          True or False
          # ans: True
          False or True
          # ans: True
          False or False
          # ans: False
          True or True
          # ans: True
aba or b
TrueFalseTrue

The not operator


          # not - inverts boolean
          not True
          # ans: False
          not False
          # ans: True
          not (5 > 3)
          # ans: False

Combining conditions


          # combining with and
          x = 10
          x > 5 and x < 15
          # ans: True
          # combining with or
          x < 5 or x > 8
          # ans: True

Short-circuit evaluation


          # and stops at first False
          False and (1/0)
          # ans: False (no error: 1/0 never runs)
          # or stops at first True
          True or (1/0)
          # ans: True (no error)

Once the left side decides the answer, Python doesn't even look at the right side.

Remember

and

True only if both are; stops at the first falsy value and returns it.

or

True if either is; stops at the first truthy value and returns it.

not

Flips truthiness and always returns True or False.

Precedence

not, then and, then or. Use brackets when in doubt.
