NumPy

Array Fundamentals

Indexing NumPy arrays: positions, slices, lists of positions, boolean masks, new axes and ellipses.

The array we will index


        import numpy as np
        one = np.array([10, 20, 30, 40, 50, 60, 70, 80])

Basic indexing

Q1 one[2] 30
Q2 one[-1] 80

    One integer picks one element, counting from 0, or from -1 at the end, exactly like a list.

    1. one[2]
    2. one[-1]

    Slicing

    A slice of an array is a view: it shares memory with one, so changing it changes one.

    1. one[1:6:2]

    Fancy indexing

    The small numbers show the order of the result: position 0 is used twice. Fancy indexing returns a copy.

    1. one[[4, 0, 3, 0]]

    Masking

    one
    one < 30
    one > 60
    &

    A comparison gives one True/False per element; & (and) and | (or) combine them.

    1. one[(one < 30) & (one > 60)]
    2. one[(one < 30) | (one > 60)]

    newaxis / None indexing

    1. one.shape
    2. one[:, np.newaxis].shape
    3. one[:, None].shape

    Higher dimensions and the ellipsis

    ... means "all the remaining axes", so two[1, ...] is two[1, :, :]: the middle 3×3 block.

    1. two[1, ...]

    Remember

    Integers and slices

    a[2], a[1:6:2]: like lists, but slices are views.

    Lists of positions

    a[[4, 0, 3]] picks in that order, as a copy.

    Masks

    a[(a > x) & (a < y)]: brackets around each comparison.

    Shape tools

    None adds an axis; ... fills in the rest.
