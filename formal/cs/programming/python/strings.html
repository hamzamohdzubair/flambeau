String Manipulation

A tour of what you can do with text: slicing, methods, formatting, checks and encodings.

Creating strings


        # creating strings
        text = "Hello, World!"
        single = 'Python'
        multiline = """This is
        a multiline
        string"""

Indexing and slicing


          text = "Hello, World!"
          text[0]  # 'H'
          text[-1]  # '!'
          text[0:5]  # 'Hello'
          text[7:]  # 'World!'
          text[:5]  # 'Hello'
          text[::2]  # 'Hlo ol!'
          text[::-1]  # '!dlroW ,olleH' (reverse)

Methods: case conversion


        text = "Hello, World!"
        text.upper()  # 'HELLO, WORLD!'
        text.lower()  # 'hello, world!'
        text.capitalize()  # 'Hello, world!'
        text.title()  # 'Hello, World!'
        text.swapcase()  # 'hELLO, wORLD!'

Methods: case checking


        text = "Hello, World!"
        text.isupper()  # False
        text.islower()  # False
        "HELLO".isupper()  # True
        "hello".islower()  # True

Methods: search


          text = "Hello, World!"
          text.find("World")  # 7 (returns -1 if not found)
          text.index("World")  # 7 (raises an error if not found)
          text.find("Python")  # -1
          text.rfind("o")  # 8 (searches from the right)
          text.count("o")  # 2
          text.count("l")  # 3
          text.startswith("Hello")  # True
          text.endswith("!")  # True

Methods: strip and replace


          text = "  Hello, World!  "
          text.strip()  # "Hello, World!"
          text.lstrip()  # "Hello, World!  "
          text.rstrip()  # "  Hello, World!"
          text.strip("! ")  # "Hello, World"
          text.replace("World", "Python")  # "  Hello, Python!  "
          text.replace("l", "L", 2)  # "  HeLLo, World!  "

strip("! ") removes any of those characters from both ends, not the string "! ".

Methods: padding


        "42".zfill(5)  # "00042"
        "hi".center(10)  # "    hi    "
        "hi".ljust(10)  # "hi        "
        "hi".rjust(10)  # "        hi"

Split


        text = "apple,banana,cherry"
        text.split(",")  # ['apple', 'banana', 'cherry']
        "one two three".split()  # ['one', 'two', 'three']
        "a-b-c".split("-", 1)  # ['a', 'b-c'] (maxsplit=1)
        # splitlines
        multiline = "line1\nline2\nline3"
        multiline.splitlines()  # ['line1', 'line2', 'line3']

Join and partition


        words = ["apple", "banana", "cherry"]
        ", ".join(words)  # "apple, banana, cherry"
        "".join(["a", "b", "c"])  # "abc"
        # partition
        "apple=red".partition("=")  # ('apple', '=', 'red')
        "apple=red".rpartition("=")  # ('apple', '=', 'red')

partition splits at the first separator, rpartition at the last; with one = they agree.

Formatting: old style


        # % formatting
        name = "Alice"
        age = 25
        "Name: %s, Age: %d" % (name, age)
        # format specifiers
        "%.2f" % 3.14159  # "3.14"
        "%5d" % 42  # "   42"
        "%-5d" % 42  # "42   "
        "%05d" % 42  # "00042"

Formatting: str.format()


        # basic formatting
        "Hello, {}!".format("World")
        "{} + {} = {}".format(2, 3, 5)
        # positional arguments
        "{1} {0}".format("World", "Hello")
        # named arguments
        "{name} is {age} years old".format(name="Alice", age=25)

str.format() specifiers


        "{:.2f}".format(3.14159)  # "3.14"
        "{:>10}".format("right")  # "     right"
        "{:<10}".format("left")  # "left      "
        "{:^10}".format("center")  # "  center  "
        "{:0>5}".format(42)  # "00042"

Formatting: f-strings


        # basic f-strings
        name = "Alice"
        age = 25
        f"Hello, {name}!"
        f"{name} is {age} years old"
        # expressions
        x = 10
        y = 20
        f"{x} + {y} = {x + y}"

f-string specifiers


        pi = 3.14159
        f"{pi:.2f}"  # "3.14"
        f"{42:05d}"  # "00042"
        f"{'text':>10}"  # "      text"
        # debugging (Python 3.8+)
        x = 42
        f"{x=}"  # "x=42"
        # multiline
        message = f"""
        Name: {name}
        Age: {age}
        """

Checking methods


        # character type checking
        "123".isdigit()  # True
        "abc".isalpha()  # True
        "abc123".isalnum()  # True
        "   ".isspace()  # True
        "Hello World".istitle()  # True
        # identifier checking
        "variable_name".isidentifier()  # True
        "123abc".isidentifier()  # False
        # printable checking
        "Hello".isprintable()  # True
        "Hello\n".isprintable()  # False

String operations


        # concatenation
        "Hello" + " " + "World"  # "Hello World"
        # repetition
        "Ha" * 3  # "HaHaHa"
        # membership
        "ell" in "Hello"  # True
        "xyz" not in "Hello"  # True
        # length
        len("Hello")  # 5
        # comparison
        "apple" < "banana"  # True (lexicographic)
        "abc" == "abc"  # True

Iterating over a string


        # iteration
        for char in "Hello":
            print(char)
        # ans: H, e, l, l, o (one per line)

Encoding and decoding


        # encode to bytes
        text = "Hello"
        encoded = text.encode()  # b'Hello'
        encoded = text.encode("utf-8")
        # decode from bytes
        decoded = encoded.decode()  # "Hello"
        decoded = encoded.decode("utf-8")

A str holds characters; bytes holds the numbers that store them. UTF-8 is the default.

Other encodings


          text = "Café"
          text.encode("utf-8")  # b'Caf\xc3\xa9'
          text.encode("ascii", "ignore")  # b'Caf'
          text.encode("ascii", "replace")  # b'Caf?'

Remember

Strings never change

Every method returns a new string; the original stays as it was.

find vs index

find returns -1 when missing; index raises ValueError.

split ↔ join

split turns a string into a list; join turns a list back into a string.

Prefer f-strings

Same format specifiers as format(), but easier to read.
