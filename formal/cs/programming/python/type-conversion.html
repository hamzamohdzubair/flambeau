Type Conversion

Turn a value of one type into another with int(), float(), str() and bool().

Converting to integer


          # string to int
          int("42")
          # ans: 42
          int("100")
          # ans: 100
          # float to int (truncates)
          int(3.14)
          # ans: 3
          int(9.99)
          # ans: 9

Converting to float


          # string to float
          float("3.14")
          # ans: 3.14
          # int to float
          float(42)
          # ans: 42.0
          float(0)
          # ans: 0.0

Converting to string


          # int to string
          str(42)
          # ans: "42"
          # float to string
          str(3.14)
          # ans: "3.14"
          # bool to string
          str(True)
          # ans: "True"

Converting to boolean


          # number to bool
          bool(1)
          # ans: True
          bool(0)
          # ans: False
          bool(-5)
          # ans: True
          # string to bool
          bool("")
          # ans: False
          bool("text")
          # ans: True

Zero and empty things are False; everything else is True.

Boolean from other types


          # list to bool
          bool([])
          # ans: False
          bool([1, 2])
          # ans: True
          # None to bool
          bool(None)
          # ans: False

Remember

int() truncates

int(9.99) is 9; it never rounds.

Text must fit

int("3.14") raises ValueError; use float() first.

Falsy values

0, 0.0, "", [], {}, None; everything else is True.

Bases

int(text, 2) reads binary, int(text, 16) hexadecimal.
