Variables & Assignment

Give a value a name with =, several at once, and swap them in one line.

Basic assignment


        # variable assignment
        x = 5
        # ans: x is 5
        name = "Alice"
        # ans: name is "Alice"
        pi = 3.14
        # ans: pi is 3.14

Names are labels


          a = 5
          b = a
          a = 10

Multiple assignment


        # assign multiple variables
        a, b, c = 1, 2, 3
        # ans: a=1, b=2, c=3
        # what are the values?
        x, y = 10, 20
        # ans: x=10, y=20

Swapping values


        # traditional swap needs a temp variable
        x, y = 5, 10
        temp = x
        x = y
        y = temp
        # ans: x=10, y=5
        # python swap
        x, y = 5, 10
        x, y = y, x
        # ans: x=10, y=5

How x, y = y, x works


          x, y = 5, 10
          x, y = y, x

Chained assignment


        # assign the same value to several variables
        x = y = z = 0
        # ans: x=0, y=0, z=0
        a = b = c = "same"
        # ans: all are "same"

Exercises

Each press reveals one answer and runs the code up to it.

Exercise 1


        # what is the value of x?
        x = 10
        # ans: 10
        # what happens after this swap?
        a, b = 5, 15
        a, b = b, a
        # ans: a=15, b=5
        # what is z after this?
        x, y, z = 1, 2, 3
        z = x + y
        # ans: 3
        # can you assign like this?
        x = y = z = 0
        # ans: yes, all are 0

Exercise 2


        # what is the value of b?
        a = 5
        b = a
        a = 10
        # ans: 5
        # what does this produce?
        x, y = 1, 2, 3
        # ans: Error: too many values to unpack
        # what is y?
        x = y = 5
        x = x + 1
        # ans: 5

Exercise 3


        # multiple assignment with calculation?
        a, b = 10, 20
        a, b = a+b, a-b
        # ans: a=30, b=-10
        # what happens here?
        x = 1
        x = x
        # ans: x is still 1
        # tricky swap
        x, y = 5, 10
        x, y = y, x+y
        # ans: x=10, y=15

The whole right side is worked out first, using the old values, before anything is assigned.

Exercise 4


        # assignment from right to left?
        a = b = 3
        b = 5
        # ans: a=3, b=5
        # what is x?
        x = 10
        # ans: 10
        # unpacking with extra values?
        x, y = [1, 2, 3]
        # ans: Error: too many values

Exercise 5


        # what about this?
        a, b, c = "abc"
        # ans: a='a', b='b', c='c'
        # swap three variables?
        x, y, z = 1, 2, 3
        x, y, z = z, x, y
        # ans: x=3, y=1, z=2
        # empty assignment?
        x, y = [], []
        # ans: x=[], y=[]

Remember

Right side first

Python evaluates everything right of =, then binds the names on the left.

Unpacking counts

x, y = … needs exactly two values, or it raises ValueError.

Names are labels

b = a makes b point at the same value; reassigning a later doesn't change b.

Swap in one line

x, y = y, x: no temp variable needed.
