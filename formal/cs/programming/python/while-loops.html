While Loops

Repeat a block for as long as a condition stays true.

How a while loop runs

  1. Check the condition.
  2. If it is True, run the indented body, then go back to the check.
  3. If it is False, skip the body and carry on after the loop.
  4. Something in the body must eventually make the condition False, or the loop never ends.

Basic while loop


        # while condition is True
        count = 0
        while count < 5:
            print(count)
            count += 1
        # ans: 0, 1, 2, 3, 4

The condition is checked before every pass, including the last one that fails.

While with countdown


        # countdown
        x = 3
        while x > 0:
            print(x)
            x -= 1
        # ans: 3, 2, 1

While with break


        # infinite loop with break
        x = 0
        while True:
            x += 1
            if x > 5:
                break
        # ans: x is 6

while True never stops by itself: break is the only way out.

While with increment


        # increment by different values
        x = 0
        while x < 10:
            x += 2
        # ans: x is 10 (after the last iteration)

Remember

Check first

The condition is tested before each pass; if it starts False the body never runs.

Change something

The body must move the condition towards False, or the loop runs for ever.

break

Leaves the loop at once, wherever it is in the body.

Truthiness

while x: keeps going while x is non-zero.
